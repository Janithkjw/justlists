# 🏭 Workshop Inventory Management - Windows Executable

## 🎯 How to Get Your Windows .exe File

### Option 1: Build It Yourself (Recommended)
1. **Download all files** from this repository to your Windows computer
2. **Double-click** `create_windows_exe.bat` 
3. **Wait** for the build to complete (2-3 minutes)
4. **Find your .exe** in the `dist` folder

### Option 2: Use PowerShell
1. **Right-click** `create_windows_exe.ps1`
2. **Select** "Run with PowerShell"
3. **Follow the prompts**

## 📋 What You Need
- **Windows 10+** (recommended)
- **Python 3.7+** installed
- **Internet connection** for downloading packages

## 🚀 Quick Start
1. **Double-click** the generated `Workshop_Inventory_Management.exe`
2. **Wait** 10-15 seconds for startup
3. **Browser opens** automatically
4. **Login:** admin / admin123
