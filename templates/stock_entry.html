Instructions
Stock Entry Process:
  1. Enter the model number (type to search existing items)
  2. If item exists, fields will auto-fill
  3. If new item, fill all required fields
  4. Set appropriate storage location
  5. Enter quantity and low stock threshold
  6. Submit to add/update stock

  • Mechanical: Bearings, Shafts, Chains, etc.
  • Pneumatic: Cylinders, Valves, Fittings, etc.
  • Other: Miscellaneous items
