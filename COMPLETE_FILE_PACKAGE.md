## 🚀 **How to Use These Files**

### **Step 1: Download All Files**
Copy all files to your Windows computer maintaining the folder structure:
```
Workshop_Inventory_Management/
├── app.py
├── launcher.py
├── requirements.txt
├── templates/
│   ├── base.html
│   ├── home.html
│   ├── login.html
│   ├── stock_entry.html
│   ├── stock_release.html
│   ├── stock_check.html
│   ├── notifications.html
│   ├── activities.html
│   └── settings.html
├── static/
│   ├── css/
│   │   └── style.css

├── create_windows_exe.bat
├── create_windows_exe.ps1
├── WINDOWS_EXECUTABLE_GUIDE.md
└── README.md
```

### **Step 2: Build Windows Executable**
1. **Double-click** `create_windows_exe.bat`
2. **Wait** for build to complete (2-3 minutes)
3. **Find** your `Workshop_Inventory_Management.exe` in the `dist` folder

### **Step 3: Run Your Application**
1. **Double-click** `Workshop_Inventory_Management.exe`
2. **Wait** 10-15 seconds for startup
3. **Browser opens** automatically at http://localhost:5000
4. **Login** with: admin / admin123
